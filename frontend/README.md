# krishiBond—Frontend

Production-ready React frontend for the Assured Contract Farming Platform, built with:

## Features implemented (frontend)

- **Auth**: register (farmer/buyer), login, JWT access + refresh token flow, protected & role-gated routes
- **Marketplace & matchmaking**: search/filter by crop and location, listing detail, suggested matches on the dashboard
- **Price negotiation**: bidding/counter-offer thread on each contract, live price benchmarks on listings
- **Contracts**: create/propose, accept/reject, milestone tracking, activity timeline
- **Secure payments**: escrow fund/release actions and status surfaced on the contract page
- **Messaging**: threaded conversations tied to listings/contracts
- **Notifications**: bell dropdown with polling and read/unread state
- **Reports**: value-by-month and status-mix charts, CSV export
- **Disputes**: file a dispute, evidence/comment thread
- **Help Center**: FAQ accordion + support ticket form
- **Profile**: editable user details
